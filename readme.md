# AI 내신 성적표

초·중학교 **중간고사·기말고사** 문제지로 AI 모델의 실력을 평가하는 웹 서비스입니다.
문제지를 올리고 정답을 입력하면, AI가 문제를 풀고 결과를 **OMR 답안지**에 선생님 채점처럼 표시합니다.

**사이트:** https://xproom.github.io/ai-csat-report/

## 기능

| 기능 | 설명 |
|---|---|
| 평가지별 옵션 표지 | 학교급·학년·학기·시험 종류·과목·학교명·시험 시간·유의사항·표지 테마(4종)를 고르면 실제 시험지 같은 표지가 만들어집니다. 목록에서는 표지 썸네일로 보입니다. |
| 문제지 업로드 | PDF·사진(JPG/PNG/WebP)을 끌어다 놓아 올리고 바로 볼 수 있습니다. 문항 구성(객관식·단답형·서술형, 4/5지선다)과 정답·배점을 입력합니다. |
| OMR 뷰어·채점 표시 | 문항 구성에 맞춘 OMR 답안지에 모델별 마킹을 보여주고, 정답은 빨간 동그라미, 오답은 빗금, 원래 정답 위치는 점선으로 표시합니다. 점수 도장, 단답·서술 답란 포함. OMR에 직접 마킹해 다른 AI 서비스나 학생 답을 기록할 수도 있습니다. |
| 평가 결과 대시보드 | 모델 순위, 과목별 득점률 히트맵, 문항 유형별·학년별 득점률, 최근 풀이를 학교급·학년·과목·시험 종류로 걸러 봅니다. 평가지마다 문항별 정답률과 AI가 가장 많이 틀린 문항도 보여줍니다. |
| AI 풀이 | 사용자 본인의 Anthropic API 키로 Claude(Opus 5.5, Sonnet 5.5, Haiku 5.5, Fable 5.2)가 문제지를 직접 풉니다. 다른 회사 모델 결과는 JSON 가져오기나 OMR 직접 입력으로 추가합니다. |
| 실제 정답 업로드 | 정답표를 CSV·TXT·JSON 파일이나 붙여넣기로 올립니다(`1,③` `1번 3` `1-3 2-5` `35124…` 등). 정답표 PDF·사진은 Claude가 읽어 옵니다. 반영 전에 현재 정답과 바뀐 문항을 비교해 보여주고, 배점 열이 있으면 함께 반영합니다. |
| AI 풀이 보기 (실시간) | 문제지를 올리면 Claude가 문항을 하나씩 풀며, 왼쪽 문제지 쪽(PDF는 실제 쪽을 렌더링) 위에 풀이를 손글씨로 써 내려가고 생각을 자막으로 보여주며, 오른쪽 OMR 답안지에 답을 마킹합니다(단답형 정수는 백·십·일 자리 칸). 끝나면 실제 정답과 비교한 채점 완료 화면(유형별 큰 점수, 모델 답 ↔ 실제 정답)을 보여줍니다. 문항별로 스트리밍 요청을 보내 문항별 실제 시간을 기록하고, 기록은 저장되어 실제 속도·배속으로 다시 재생할 수 있습니다. 실시간 기록이 없는 풀이는 추정 시간으로 재생합니다. |
| 성능 평가 | 실제 정답 대비 정확도와 수행 시간(전체·문항당·정답 1개당·분당 문항), 토큰을 모델별로 비교합니다. 정확도-시간 산점도에서 균형 최적 모델(정확도와 속도 모두 뒤지지 않는 모델)을 표시하고, 문항별 실제 정답과 모델 답을 나란히 비교합니다(답이 갈린 문항·모두 틀린 문항 필터). CSV로 내려받을 수 있습니다. |
| 수행 시간 기록 | Claude 실행은 요청부터 응답까지 실제 시간을 잽니다. OMR 직접 입력은 첫 마킹부터 마지막 마킹까지 시간을 기록하고, 가져온 결과는 `durationMs`나 `seconds` 값 또는 성능 평가 표에서 직접 입력합니다. |
| 서술형 채점 | 서술형은 자동 채점하지 않고, 답을 읽고 점수를 입력하면 총점에 반영됩니다. |
| 백업 | 모든 데이터는 브라우저(IndexedDB)에만 저장됩니다. 설정에서 문제지 파일을 포함한 백업을 내려받고 복원할 수 있습니다. |

## 결과 가져오기 형식

```json
[
  { "model": "GPT-6.2", "seconds": 84.5, "answers": { "1": "3", "2": "5", "21": "12" } },
  { "model": "Gemini 4", "answers": [{ "no": 1, "answer": "3" }] }
]
```

## 개발

```powershell
cd web; npm ci; npm run dev
```

- 테스트: `npm test` (채점·답 파싱·결과 가져오기)
- 빌드: `npm run build` (배포 경로는 `VITE_BASE` 환경 변수, 기본 `/`)
- `main`에 push하면 GitHub Actions가 테스트 후 GitHub Pages에 배포합니다.

### 구조 (`web/src`)

- `lib/schema.js` 평가지·풀이 데이터 형식, `lib/grading.js` 채점, `lib/aiRunner.js` Claude 호출, `lib/db.js` IndexedDB
- `components/PaperCover.jsx` 표지, `components/OmrCard.jsx` OMR 답안지, `components/RunPanel.jsx` 풀이 추가
- `lib/liveSolve.js` 문항별 실시간 풀이(스트리밍·시각 기록), `lib/replay.js` 재생 상태 계산, `components/SolveViewer.jsx` AI 풀이 보기 화면, `components/CompactOmr.jsx` 세로형 OMR, `components/GradeSheet.jsx` 채점 완료 화면
- `pages/` 홈, 새 평가지(3단계), 평가지 상세(표지·문제지·정답·OMR·AI 풀이 보기·결과·성능 평가), 대시보드, 설정

## 주의

- AI 풀이 요청은 브라우저에서 Anthropic API로 바로 갑니다. API 키는 이 브라우저에만 저장되며, 사용 한도를 정한 전용 키를 권장합니다.
- 학교 시험 문제지의 저작권은 출제 학교·교사에게 있습니다. 이 서비스는 문제지를 서버에 올리지 않습니다.
